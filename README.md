## About the project

This is the source code for my portfolio website. It brings selected audiovisual work, a short introduction, experience, and education together in one responsive experience.

The visual direction keeps things editorial and minimal: warm off-white surfaces, deep ink typography, and a restrained blue accent.

## What’s inside

- A responsive navigation and mobile menu
- An editorial-style hero section and profile photography
- A curated work section with project details
- About, work experience, and education sections
- Contact links and downloadable CV
- Scroll reveals, motion details, and back-to-top interaction

## Built with

| Technology | Role |
| --- | --- |
| HTML | Page structure and content |
| CSS | Layout, responsive styling, and animation |
| JavaScript | Navigation, project interactions, and interface behavior |
| Google Fonts | Syne, Space Grotesk, Manrope, and DM Mono |

## Run locally

No build step is required. Clone or download the repository, then open `index.html` in a browser.

For a local web server, you can use the **Live Server** extension in Visual Studio Code.
